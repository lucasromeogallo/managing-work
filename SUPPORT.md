# Support

This repository provides beginner-friendly documentation and starter materials; it does not operate a hosted automation service or provide support for client deployments.

For problems with the repository content, open an issue without including credentials, client names, personal information, customer records, or confidential business details. For a suspected security issue or accidental exposure, follow the private reporting guidance in [SECURITY.md](SECURITY.md) instead of posting publicly.

For support with a specific client deployment, use the support and escalation contact agreed with that client. Do not send client data or credentials in a public issue.
